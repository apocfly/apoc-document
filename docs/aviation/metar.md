# 气象报文解读

## 前言

航空气象报文是机场气象观测的标准化产物，
[`例行观测报`|METAR]、[`特殊观测报`|SPECI]与[`机场预报`|TAF]共同描述了机场及周边的主导气象条件，
是飞行前了解目的机场天气的第一手资料，也是[`通播`|ATIS]的数据来源。

本文以[《国际民用航空公约》附件 3《国际航空气象服务》]的编报规则为蓝本，逐编组拆解 METAR 报文结构，并简述 TAF 报文的差异。

## 1. 报文种类

| 种类    | 含义    | 说明                                              |
|:------|:------|:------------------------------------------------|
| METAR | 例行观测报 | 无论有无飞行任务，每小时或每半小时观测发布一次                         |
| SPECI | 特殊观测报 | 当气象条件达到或通过本场标准或运行最低标准，<br/>或重要天气现象出现、终止、强度变化时发布 |
| TAF   | 机场预报  | 预报机场未来 9 或 24 小时的主导气象条件，与 METAR 分开发布            |

> [!TIP]
> 识别码后可出现两种修饰
> - `AUTO` 表示由自动观测系统发布，无人工干预
> - `COR` 表示对前一份报文的更正

触发 SPECI 的重要天气现象包括，冻降水、冻雾、[中或大的降水|含阵雨]、低吹/高吹的尘沙雪、尘暴、沙暴、[雷暴|伴随或不伴随降水]
、飑、漏斗云。

## 2. METAR 结构总览

[一份标准的ICAO METAR如下|报文经过部分加工以便讲解]：

```text
METAR ZGHA 150700Z 03004G10MPS 360V060 6000 R36R/P1500 
SHRA FEW030CB SCT035TCU BKN050 31/19 Q1015 NOSIG
```

| 编组    | 示例                          | 含义                 |
|:------|:----------------------------|:-------------------|
| 报告类型  | `METAR`                     | 例行观测报              |
| 站名    | `ZGHA`                      | ICAO四字机场代码         |
| 观测时间  | `150700Z`                   | 15日 07:00 UTC      |
| 风向风速  | `03004G10MPS`               | 风030°、4米秒、阵风10米秒   |
| 风向变化  | `360V060`                   | 风向在360°–060°间摆动    |
| 能见度   | `6000`                      | 主导能见度6000米         |
| 跑道视程  | `R36R/P1500`                | 跑道36R接地端RVR超过1500米 |
| 现时天气  | `SHRA`                      | 阵雨                 |
| 云     | `FEW030CB SCT035TCU BKN050` | 见下文云组详解            |
| 温度/露点 | `31/19`                     | 气温31℃、露点19℃        |
| QNH   | `Q1015`                     | 修正海压1015百帕         |
| 趋势    | `NOSIG`                     | 未来两小时无重要变化         |

METAR 的编组规则同样适用于 SPECI 与 TAF

## 3. 逐编组详解

### 3.1 报头识别

- **报告类型**：`METAR`或`SPECI`；
- **站名**：ICAO四字代码；
- **观测时间**：`日时分Z` 格式，`Z`表示世界协调时，如 `150700Z`。

若一个天气通告包含多个机场的报告，`METAR`/`SPECI` 由 `SA`/`SP` 取代，各分项报中不再重复报告类型与观测时间。

### 3.2 地面风

- 风向以真北为基准、按最近10°取整的三位数字表示，后跟观测前 10 分钟的平均风速及单位

> [!TIP]
> 中国大陆内机场的报文风速单位通常为[`MPS`|米]，欧美机场多为[`KT`|节]，也有使用[`KMH`|千米时]为单位的。读取时注意区分。

- 最大阵风超过平均风速10节或更多时，加`G`报最大阵风，如 `03004G10MPS`；
- [`静风`|指平均风速小于0.5米秒]编报`00000`；
- 风向不定编报[`VRB`|观测时段内风向变化超过 180° 或无法确定风向]，如`VRB02MPS`；
- 观测前10分钟内风向变化达60°或以上且平均风速超过3节时，按`顺时针`方向报两个极值风向，用`V`分隔，如`280V350`。

### 3.3 水平能见度

- 报告**主导能见度**：观测值达到或超过机场周围或机场地面一半范围的最大能见度；
- 当主导能见度不足1500米，或低于某方向最低能见度且主导能见度改善时，还需报告该方向最低能见度，如
  [`1400SW 6000N`|西南方向1400米，北面6000米]；
- 小于800米按50米取整；800米至5公里按100米取整；大于5公里按整公里取整；能见度10公里或以上编报`9999`；小于50米编报`0000`。

### 3.4 [RVR|跑道视程]

- 编组格式：`R` + 跑道编号 + `/` + 接地端RVR值，如`R24L/1100 R24R/1150`，RVR单位为米；
- 超出设备探测上限在RVR值前加`P`，如`R24/P1500`；低于设备探测下限加`M`，如`R24/M0050`；
- 报告观测前10分钟内，
    - 若[呈现上升趋势|前后5分钟平均值变化达100米或以上]，在RVR值后加`U`，如`R24/1100U`
    - 若[呈现下降趋势|前后5分钟平均值变化达100米或以上]，在RVR值后加`D`，如`R24/1100D`
    - 若无明显变化，在RVR值后加`N`，如`R24/1100N`
- 若[有重大短时波动|1分钟平均极值与10分钟平均值之差超过50米或平均值的20%，取较大者]，按从小到大报极值并用`V`分隔，如
  `R24/0950V1100`。

### 3.5 天气现象

- 每个天气编组由"强度指示 + 描述符/现象"构成，例如：[`SHRA`|阵雨], [`FZRA`|冻雨], [`+TSRA`|强雷雨]
- 不同种类的降水混合以联合形式报出，如[`RASN`|雨夹雪]、[`-DZHZ`|小毛毛雨伴轻雾]；
- 能见度大于 5000 米时，不报告 `BR`、`HZ`、`FU`、`IC`、`DU`、`SA`。

| 强度/地点 | 符号   | 描述符  | 含义          |
|:------|:-----|:-----|:------------|
| 轻度    | `-`  | `MI` | 浅的          |
| 中等    | 无    | `BC` | 散片状         |
| 强度大   | `+`  | `DR` | 低吹          | 
| 在附近   | `VC` | `BL` | 高吹          | 
|       |      | `SH` | 阵性          | 
|       |      | `TS` | 雷暴          |
|       |      | `FZ` | 冻结、过冷       |
|       |      | `PR` | 部分、覆盖机场部分范围 | 

| 降水   | 含义     | 视程障碍 | 含义  | 其他   | 含义          |
|:-----|:-------|:-----|:----|:-----|:------------|
| `DZ` | 毛毛雨    | `BR` | 轻雾  | `PO` | 尘/沙旋风、尘卷风   |
| `RA` | 雨      | `FG` | 雾   | `SQ` | 飑           |
| `SN` | 雪      | `FU` | 烟   | `FC` | 漏斗云、龙卷风、水龙卷 |
| `SG` | 米雪     | `VA` | 火山灰 | `SS` | 沙暴          |
| `IC` | 冰针     | `DU` | 浮尘  | `DS` | 尘暴          |
| `PE` | 冰粒     | `SA` | 沙   |      |             |
| `GR` | 冰雹     | `HZ` | 霾   |      |             |
| `GS` | 小冰雹、雪粒 |      |     |      |

### 3.6 云

云组为6字符：前3位为云量，后3位为[云底高/100|单位为英尺，如果单位为米则改为/30]；云状只报[`CB`|积雨云]与[`TCU`|浓积云]。

| 符号    | 云量    | 通俗叫法 |
|:------|:------|:-----|
| `FEW` | 一至二分云 | 少云   |
| `SCT` | 三至四分云 | 疏云   |
| `BKN` | 五至七分云 | 多云   |
| `OVC` | 八分云   | 满天云  |

- 云组按云底高度递增次序报告，如`FEW005 SCT010 SCT018CB BKN025`
- 天空无云但不满足CAVOK条件时报[`SKC`|sky clear]
- [5000英尺|或最高的扇区安全高度，两者取高]以下无云且无CB/TCU时报[`NSC`|no significant cloud]
- 天空状况不明以`VV` + [垂直能见度/100|单位为英尺，如果单位为米则改为/30]，如`VV003`；垂直能见度不可测时报`VV///`

### 3.7 CAVOK

当同时满足以下条件时，能见度、RVR、天气现象与云四组以`CAVOK`取代：

1. 能见度10公里或以上
2. [5000英尺|或最高的扇区安全高度，两者取高]以下无云，且任何高度无CB/TCU
3. 机场及其附近无重要天气现象

### 3.8 温度/露点

- 以摄氏度报告，前缀`M`表示零下，如 `10/03`、`01/M01`；露点缺失报 `10///`；
- 温度值向上取整，`+2.5`报`3`，`-2.5`报`-2`。

### 3.9 修正海压

- `Q` + 近似到整百帕的四位数值，小于1000时首位补 0，如`Q1015`、`Q0995`；
- 以英寸汞柱为单位的地区，用`A`前缀、精确到百分之一英寸并省略小数点，如`A3027`。

> [!NOTE]
> QNH、QFE、QNE 与过渡高度层等概念的完整讲解见[气压基准与高度表拨正程序](./QNH)。

### 3.10 补充信息

- **最近天气**：[上一次观测时段|或前一小时内，取较晚者]出现、现已不存在的代表天气，`RE` + 现象代码，如`RETS REGR`
- **风切变**：起飞或进近方向、跑道平面上方1600英尺以下存在风切变时，以`WS`编组报告，如 `WS RWY20`、`WS ALL RWY`

### 3.11 跑道状况

有覆盖性降水或其他跑道污染物时，在报文末尾附跑道状况编组。

| 污染物 | 含义       | 污染程度 | 含义      |
|:----|:---------|:-----|:--------|
| `0` | 洁净干燥     | `1`  | ≤10%    |
| `1` | 潮湿       | `2`  | 11–25%  |
| `2` | 湿/积水     | `5`  | 26–50%  |
| `3` | 霜或冰晶     | `9`  | 51–100% | 
| `4` | 干雪       | `/`  | 未报告     |
| `5` | 湿雪       |      |         | 
| `6` | 雪水       |      |         | 
| `7` | 冰        |      |         | 
| `8` | 压实雪      |      |         | 
| `9` | 冻结的车辙/沟脊 |      |         |
| `/` | 未报告      |      |         | 

| 污染深度    | 含义       | 摩擦系数/刹车效应 | 含义        |
|:--------|:---------|:----------|:----------|
| `00`    | 小于1毫米    | `01-90`   | 摩擦系数的小数部分 |
| `01–90` | 深度，单位厘米  | `91`      | 刹车效应差     |
| `91`    | 10厘米     | `92`      | 刹车效应中到差   |
| `92`    | 15厘米     | `93`      | 刹车效应中     |
| `93`    | 20厘米     | `94`      | 刹车效应中到好   |
| `94`    | 25厘米     | `95`      | 刹车效应好     |
| `95`    | 30厘米     | `99`      | 数值不可靠     |
| `96`    | 35厘米     | `//`      | 未报告       |
| `97`    | 40厘米     |           |           |
| `98`    | 40厘米以上   |           |           |
| `99`    | 跑道关闭/清理中 |           |           |
| `//`    | 未报告/可忽略  |           |           |

**旧式8位数字组**，如`88290928`：

- 第1-2位表示跑道号：`27`代表跑道27；`77`代表跑道27R；`88`代表所有跑道；`99`代表重复先前信息
- 第3位表示污染物
- 第4位表示污染程度
- 第5-6位表示污染深度
- 第7-8位表示摩擦系数/刹车效应

**新式编组**，如`R24/6205//`：`R` + 跑道号 + `/` + 污染物 + 程度 + 深度 + 刹车效应

### 3.12 趋势

趋势预报描述观测时刻后两小时内的预期重要变化，仅在部分机场提供：

- 变化指示：[`BECMG`|becoming，逐渐转变]或[`TEMPO`|temporary，短时波动]，可后跟`FM`/`TL`/`AT`+UTC时间组
- 预报时段内无重要变化时报`NOSIG`
- 示例：`BECMG FM1100 25035G50KT`、`TEMPO FM0630 TL0830 3000 SHRA`

### 3.13 附注

`RMK` 之后为选择性附注部分，内容与格式由各国自行决定、不向国外发布。  
譬如美国报文的`RMK`中常见自动站类型`A01`/`A02`、最大风速`PK WND`、风向转变时间`WSHFT`、海平面气压`SLP`、逐时降水`Prrr`
等编组。  
如需深入研究，可查阅各国气象部门发布的METAR标准格式说明。

## 4. 自动观测报文

无人工监控的自动观测报文中：

- 日期组与地面风组之间插入 `AUTO`；自动报文中的天气现象未经人工核实，需谨慎对待
- 主导能见度后加[`NDV`|no directional variation，无方向变化报告]，如`6000NDV`
- 现时天气无法探测报`//`；传感器无法识别降水类型报[`UP`|unidentified precipitation，识别不出的降水]或
  [`FZUP`|冻结的未知降水]
- 未探测到云报`NCD`；云高/云状探测失效报 `/////////`；探测到CB/TCU但高度云量未知报`//////CB`
- 此前报过中等或以上的未知降水消失后报`REUP`
- 闪电编组：`TS`表示机场约8公里内探测到闪电，`VCTS`表示约 8–16 公里内探测到闪电但机场无雷暴

示例：`METAR ZYCH 140900Z AUTO 24003MPS 190V270 //// // ////// 23/11 Q1017=`

## 5. 完整解码示例

以一份复杂报文为例：

```text
METAR WMKK 090800Z 23004KT 150V310 3000 1000N 
-TSRA FEW008 FEW017CB SCT030 31/25 Q1006 NOSIG
```

| 编组                       | 解读                            |
|:-------------------------|:------------------------------|
| `METAR WMKK`             | 机场WMKK例行观测                    |
| `090800Z`                | 09日08:00UTC                   |
| `23004KT`                | 风230°、平均4节                    |
| `150V310`                | 风向在150°–310°间变化               |
| `3000 1000N`             | 主导能见度3000米，北面1000米            |
| `-TSRA`                  | 小阵雨                           |
| `FEW008 FEW017CB SCT030` | 800英尺少云、1700英尺有少量积雨云、3000英尺疏云 |
| `31/25`                  | 气温31℃、露点25℃                   |
| `Q1006`                  | 修正海压1006百帕                    |
| `NOSIG`                  | 未来两小时无重要变化                    |

完整译文为：
> 吉隆坡国际机场例行观测报，发布时间世界协调时09日08:00。风向230度，平均风速4节，风向在150度与310度之间变化。
> 主导能见度3000米，北面能见度1000米。本场有小阵雨，在800英尺有少云，1700英尺有少量积雨云，3000英尺有疏云。
> 气温31摄氏度，露点25摄氏度。修正海压1006百帕。未来两小时无重要变化。

## 6. TAF 机场预报

TAF 描述机场未来的主导气象条件，常见9小时与24小时两种：9小时预报每3小时更新发布，
12–24小时预报每6小时更新发布，必要时发布[`AMD`|修正报]、[`COR`|更正报]与[`CNL`|取消报]。

```text
TAF ZGHA 090302Z 0906/1006 36003MPS 4000 BR SCT050 TX30/0907Z TN16/0922Z
```

与 METAR 的主要差异：

- **有效期组**：`0906/1006`表示09日06时至10日06时止
- **风**：预报的是预期盛行风向；因盛行风向不确定时用`VRB`
- **能见度**：仅预报最小能见度值，格式与METAR相同
- **天气**：无重要天气时省略；预报天气结束后用[`NSW`|no significant weather]表示
- **云**：预报晴空报`SKC`；不满足SKC/CAVOK且无CB/TCU、无[5000英尺|或最高扇区安全高度，取高者]以下其他云时报`NSC`。

部分24小时TAF还包含最高/最低温度预报[`TX30/0907Z TN16/0922Z`|最高30℃出现于09日07:00UTC，最低16℃出现于09日22:00UTC]
以及航线性质的积冰（`6Ihhht`）与颠簸（`5Bhhht`）编组，详细编码规则见[《国际民用航空公约》附件 3《国际航空气象服务》]
