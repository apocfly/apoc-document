# ApocClient 安装使用教程

## 1. 前言

ApocClient是由APOC技术团队自主开发的桌面联飞客户端，除去标准联飞功能外，额外集成语音通信与CPDLC/ACARS数据链通信功能。

ApocClient目前支持微软模拟飞行 MSFS 2020/2024 以及 X-Plane 11/12 四款主流模拟器。
针对X-Plane用户，我们随安装程序一并提供配套插件xApocFly，安装时即可一键部署，无需额外手动操作。

无论您是初次接触连飞的新飞友，还是希望在新平台继续翱翔的老手，我们都希望这篇教程能成为您顺利启程的得力助手。  
现在，请跟随我们的指引，轻松完成安装与设置，开启您的联飞之旅——期待在虚拟蓝天下，与您安全、顺畅地相遇！

## 2. 安装前准备

- ApocClient安装包
  > [!NOTE]
  > 您可以前往我们[下载站](https://file.apocfly.com/ApocClient)或者[官方QQ群](https://qm.qq.com/q/KY7K0yo0eY)下载最新版本的ApocClient安装包  
  > **截止编写本文**，最新版本为`1.0.0-beta.13`
- Windows 10/11 64位操作系统
- 至少`256MB`空闲磁盘空间
- 模型库已经下载并放置到正确位置
  > [!TIP]
  > 如果您不知道模型库是什么，请看[模型库下载与安装]()
- 没有运行中的模拟器

> [!CAUTION]
> **截止编写本文**，ApocClient仅支持`微软模拟飞行2020`、`微软模拟飞行2024`、`XPlane 11`和`XPlane 12`  
> 对于其他模拟器，请使用[Swift](./swift.md)与[AudioClient](./audio_client.md)
